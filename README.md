# DCS CARP-LZ Weather Tool

A simple extension that makes airdrop planning easier by pulling live weather data at your drop zone and planned drop altitude. Also works well for pulling FARP/LZ Weather

---
## Prerequisites 
DCS Scratchpad from @rkusa available here: https://github.com/rkusa/dcs-scratchpad

## Installation 
1. Install DCS Scratchpad 
2. Download the latest release on the right side of this webpage
3. Unzip the file, and place the script inside \Saved Games\DCS\Scripts\Scratchpad\Extensions
4. Restart or Launch DCS 
---
## Using the Weather Tool 
1. Press Lctrl+Lshift+X or whatever keybind you have assigned to open DCS Scratchpad
2. Three buttons should appear beneath the scratchpad box- Form, CARP, and LZ. 
3. Start by pressing FORM, then either CARP or LZ. 
4. Edit the waypoint name in the form template to whatever you choose
5. Enter coordinates and drop altitude. If using LZ, ignore drop altitude field
6. Press either CARP or LZ, and scroll to the bottom. Voila! Specific wind, temperature, pressure, and elevation data for the entered coordinates will appear.
